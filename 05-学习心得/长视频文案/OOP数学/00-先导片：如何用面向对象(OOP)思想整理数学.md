# 1.如何用面向对象(OOP)思想整理数学

为什么这种把知识“类化”和“方法化”的思维，对408考生极度有效？
1. 极度契合计算机考研(408)的底层思维
    >用写代码的“类”和“对象”去解构数学，相当于提前打通了“数学”和“计算机”的任督二脉。《数据结构》和《操作系统》,这两门课最核心的思想就是“抽象”和“封装”。408数学里的函数就是数据结构里的抽象数据类型(ADT)。
2. 构建真正的“知识体系”而非“零散知识点”:
   >传统数学学习是零散的(学了一个公式、背了一个性质)，用OOP学习，你建的是一个架构。
   数学概念=类(Class):规定了事物的本质属性(字段)和行为(方法)。
   具体模型=对象(Object):例如 y=x^2 是二次函数 类的实例，y=sin(x)是三角函数 类的实例。
   做题技巧 = 静态工具方法 (static Utility Method) :例 Mathutil.calcDefiniteIntegral(f, a, b)
(计算定积分)。
3. 完美的长期记忆与迭代:
   >你现在距离2028年还早，用这种方法建知识库，相当于给自己写了一个“数学知识框架库”。以后每学到一
个新知识点(比如洛必达法则)，你只需要往里面“追加(extend)”一个新的方法或者属性，你的体系就会越来越丰满，而不会像别人那样学了忘、忘了学。


# 2.把握OOP的重点

用OOP整理知识体系时，最强大的不是“继承”，而是“**多态**(Polymorphism)
在数学里，这就相当于:不管你是指数函数、对数函数还是三角函数，只要它们都继承了 AbstractFunction那么当你遇到“求定积分面积”这个任务时，你可以调用同一个接口 func.integrate()，计算机(或者你大脑中的思维模型)会自动根据它具体是哪个类，去调用对应的积分公式。


# 3.OOP复盘三步法
第一步:找共性提炼“抽象基类(Abstract Class)
>周末复盘时，看看这周学了哪些看似不相关的东西，尝试找出它们的共同点。
比如:这周学了“求极限”和“求导数”，你可以抽象出一个Mathoperator 类，里面包含checkCondition()(检查前提条件，如0/0型)和 Execute()(执行计算)

第二步:找差异，实现"继承与多态(Inheritance & Polymorphism)"
>把具体的知识点作为子类，把它们的"特殊性质”作为重写的方法(Override)。
比如:三角函数和绝对值函数都继承自函数，但是对于不同函数求导的方法是不一样的，这就是多态。

第三步:把错题和技巧封装为"工具类(Utility/Helper)Methods)
>平时做错的题、总结出的秒杀技巧，不要只记在错题本上，把它们当成一个个“静态工具方法(Static Methods)
比如:遇到洛必达法则失效的题，你可以封装一个MathTools.HandleLHopitalFail()方法
里面记录：“当求导后极限不存在时，转用泰勒公式或等价无穷小替换”

# 4.接口拆解三步法

第一步:找“名词”，确定接口名
>看看你要抽象的东西叫什么。
>场景:我们要定义一个“数学函数”。
>提炼:接口名就叫IMathFunction

第二步:找“动词”，确定方法(Methods)
>这个对象能干什么?必须干什么?
>场景:任何一个函数，给它一个a，它必须能算出一个y。
>提炼:必须有一个方法叫 calculate(doublex)，返回一个double

第三步:找"属性”，确定状态(Properties)
>这个对象有什么特征?
>场景:每个函数都有自己的定义域(比如有的函数。不能等于0)。
>提炼:必须有一个属性叫 Domain(定义域)。

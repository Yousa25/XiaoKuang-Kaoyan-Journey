*   **核心观点**：别死记硬背！在程序员眼里，定义域和值域就是面向对象编程（OOP）里的**“输入参数校验”**与**“返回值类型”**，而区间，就是最优雅的**“数据类型”**。

**2. 概念降维：用OOP重构“三要素”**
*   **函数 = 一个封装好的方法 (Method)**
*   **定义域 (Domain) = 参数校验规则 (Parameter Validation)**
    *   本质：决定函数“能接受什么输入”。
    *   OOP映射：就像方法里的 `if (x < 0) throw new Exception()`，不满足条件的输入直接拦截。
*   **值域 (Range) = 返回值集合 (Return Type)**
    *   本质：决定函数“能输出什么结果”。
    *   OOP映射：就像方法的返回类型 `int` 或 `string`，它受限于内部逻辑，不是随便什么值都能返回。

**3. 核心高潮：区间（Interval）的面向对象实现**
*   **区间的本质**：连续数据的“边界约束类”。
*   **括号的多态**：
    *   中括号 `[ ]` = `>=` 或 `<=`（包含边界，实心点）。
    *   小括号 `( )` = `>` 或 `<`（不包含边界，空心点）。
*   **无穷大 `∞` 的特殊性**：它不是一个具体的数字，而是一个“趋向符号”，所以在OOP里，它永远只能用开区间 `( )` 来包裹。

**4. 实战演练：代码思维解高数题**
*   **案例**：求 $f(x) = \sqrt{x-1}$ 的定义域。
*   **程序员思维**：
    *   识别约束：偶次根式下必须 $\ge 0$。
    *   写条件：`x - 1 >= 0`。
    *   解出结果：`x >= 1`。
    *   类型转换（写成区间）：`[1, +∞)`。

**5. 结尾钩子 (Call to Action)**
*   总结：高数不是玄学，是严谨的逻辑系统。

```csharp
public class Interval {
    public double Start { get; set; } // 左端点
    public double End { get; set; }   // 右端点
    public bool IsStartInclusive { get; set; } // 左端点是否包含（对应中括号）

```
这里，我们用布尔值 `IsStartInclusive` 来控制边界。如果是 `true`，就是中括号 `[`；如果是 `false`，就是小括号 `(`。这就是面向对象里的**封装**，把区间的规则死死锁在类里面。

**第二步：定义函数类与校验逻辑**
接着，我们写一个函数类，比如 `SqrtFunction`（根号函数）。
```csharp
public class SqrtFunction {
    // 求解定义域的方法
    public Interval GetDomain() {
        // 根号下的表达式 x - 1 >= 0，解得 x >= 1
        return new Interval {
            Start = 1,
            End = double.PositiveInfinity,
            IsStartInclusive = true,  // x=1 合法，用中括号
            IsEndInclusive = false    // 无穷大永远不合法，用小括号
        };
    }

    // 判断输入值是否在定义域内
    public bool IsValidInput(double x) {
        var domain = GetDomain();
        bool leftValid = domain.IsStartInclusive ? (x >= domain.Start) : (x > domain.Start);
        bool rightValid = domain.IsEndInclusive ? (x <= domain.End) : (x < domain.End);
        return leftValid && rightValid;
    }
}
```
大家看这个 `IsValidInput` 方法，这就是高数里的**参数校验**！传入一个 `x`，程序会自动判断它是否满足定义域的条件。

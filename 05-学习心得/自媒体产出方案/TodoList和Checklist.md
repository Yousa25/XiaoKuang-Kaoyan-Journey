### 📝 To-Do List：从“一个想法”到“全网分发”的执行流

当你脑子里突然蹦出一个好点子（比如：用OOP讲马原、吐槽在职考研的崩溃瞬间），请按以下 5 步执行：

#### 1. 灵感捕获与验证（15分钟）
*   [ ] **记录灵感**：立刻用手机备忘录或 Notion 记下核心关键词，防止遗忘。
*   [ ] **灵魂三问**：这个选题解决谁的问题？读完能得到什么？我能不能用3点讲清楚？
*   [ ] **AI 辅助验证**：把选题丢给大模型，让它评估热度、竞争度，并帮你生成一个包含“痛点开篇、核心逻辑、实操步骤”的粗大纲。

#### 2. 生产“母内容”（30-60分钟）
*   [ ] **深度输出**：用你最擅长的程序员思维，把知识点写透。不要管排版，先把代码逻辑、核心观点、大白话解释全部写出来。
*   [ ] **强制去水**：初稿写完后，强制删减 30% 的废话，提升单句的信息密度，现在的用户没有耐心看铺垫。

#### 3. 多平台“重构”分发（30分钟）
*   [ ] **小红书（图文版）**：提炼核心逻辑图/代码截图，配上大字标题。正文结构改为：痛点引入 ➡️ OOP代码展示 ➡️ 引导互动（如“需要模板扣1”）。
*   [ ] **抖音（短视频版）**：从母内容中提取最刺激的一个痛点，写成 15-60 秒口播脚本。开头 3 秒必须抛出反差（如：“27岁码农用C#写政治”），删掉所有停顿，加快语速。
*   [ ] **B站（中长视频版）**：把完整的代码推导过程录屏，配上你的解说，保留极客式的深度和真实备考心路历程。

#### 4. 黄金期运营（发布后 30-60 分钟）
*   [ ] **置顶神评论**：自己发一条带福利或引导讨论的评论并置顶（如：“想要这套OOP思维导图的，评论区扣‘1’，我私发你”）。
*   [ ] **秒回互动**：发布后 1 小时全程在线，及时回复所有评论、私信，拉高账号的初始互动数据。
*   [ ] **主动出击**：去同赛道（考研、程序员）的爆款视频下发表高质量评论，吸引精准粉丝。

#### 5. 极简复盘（睡前 5 分钟）
*   [ ] **数据归因**：看一眼今天发的数据。点击率低说明封面/标题不行；完播率低说明前3秒没抓住人或中间废话多；收藏低说明干货不够。
*   [ ] **明日规划**：写下明天最重要的 1 件事。

### 🔍 Check List：发布前的“防翻车”自查清单

内容再好，一旦违规被限流就全白搭。每次点击“发布”前，请快速过一遍这 4 个维度的红线：

#### 1. 技术检测（AI味与同质化）
*   [ ] **AI 痕迹检测**：如果用了 AI 辅助，句式是否太整齐、缺乏情绪变化？必须人工改写，注入你的个人经验和独特视角（AI 只能做 80% 体力活，20% 的灵魂必须你来）。
*   [ ] **同质化排查**：用工具或人工检查，你的观点和表达方式是否和网上现有的内容高度重合？如果没有提供新的增量价值，平台不会给流量。
*   [ ] **敏感词过滤**：检查文案、标题、封面，是否包含极限词（如“最”、“绝对”）或平台敏感词。

#### 2. 内容合规红线（绝不触碰）
*   [ ] **版权与原创**：引用的书籍、古文、他人文章是否标注了出处？千万不要把大段搬运或 AI 生成的内容标记为“原创”，极易触发滥用原创处罚。
*   [ ] **配图安全**：是否使用了未授权的网络图片？如果用了 AI 生成的配图，请在角落标注“配图：AI生成｜本公众号”，既防侵权又防平台判定为机器批量生成。
*   [ ] **价值观导向**：内容是否贩卖了过度焦虑？是否涉及了无资质的医疗、金融建议或极端情绪对立？（保持客观包容，传递积极破局的方法）。

#### 3. 账号行为红线（防限流）
*   [ ] **站外引流**：简介、正文、评论区是否直接留了微信号、二维码或外部链接？（绝对禁止，请用“主页群聊”或“私信发资料”等软性合规方式）。
*   [ ] **诱导行为**：是否有“不转不是中国人”、“点赞必过”等利诱转发/关注的违规话术？
*   [ ] **数据造假**：绝对不要买粉、刷阅读、刷点赞，一旦被系统识别，账号直接降权甚至封禁。

#### 4. 基础设置自查
*   [ ] **视觉统一**：封面风格、字体、排版是否与你“27岁程序员考研”的 IP 人设保持一致？
*   [ ] **账号状态**：确认近期没有收到平台的违规警告或未处理通知。

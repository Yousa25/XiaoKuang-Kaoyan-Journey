Chapter 01 映射与函数 (Mapping & Functions)

🏗️ 核心抽象：什么是函数？

在 OOP 视角下，函数不是简单的公式，而是一个封装了“映射法则”的对象。

// 定义映射接口
interface IMapping<TInput, TOutput> {
  TOutput Execute(TInput x); // 映射法则 f(x)
  Domain GetDomain(); // 获取定义域
  Codomain GetCodomain(); // 获取值域
}

🧬 核心特性 (Properties)

函数的四大特性，本质上是该对象的“状态评估方法”：

  • 奇偶性 (Parity)：评估对象是否关于原点或Y轴对称。
  • 单调性 (Monotonicity)：评估输出值随输入值递增/递减的趋势。
  • 周期性 (Periodicity)：评估对象是否存在状态重置循环。
  • 有界性 (Boundedness)：评估输出值是否被限制在某个阈值内。

### 2.4.1 案例分析：图书表的顺序存储结构类型定义

**【案例背景】**
需要设计一个数据结构，用来存储和管理一组图书信息。
*   **数据元素**：每一本图书（包含ISBN、书名、价格）。
*   **数据结构**：由于图书表长度可变（可增删），且需要按顺序存取，采用**顺序存储结构（顺序表）**。

#### 1. 结构体定义（C语言伪代码提炼）

```c
#define MAXSIZE 10000  // 宏定义最大容量，防止溢出

// 1. 定义数据元素的结构体（单条图书信息）
typedef struct {
    char no[20];       // 图书ISBN（字符串）
    char name[50];     // 图书名字（字符串）
    float price;       // 图书价格（浮点数）
} Book;

// 2. 定义线性表的顺序存储结构（图书表）
typedef struct {
    Book *elem;        // 指向顺序表首地址的指针（动态分配内存空间）
    int length;        // 记录当前表中的实际图书个数
} SqList;
```

#### 2. 核心考点提炼（编译倒逼与底层理解）
*   **指针与动态数组**：`Book *elem;` 为什么不直接写 `Book elem[MAXSIZE];`？
    *   **答案**：使用指针 `*elem` 是为了配合动态内存分配（如 `malloc` 或 `realloc`）。这样可以根据实际需要分配空间，比静态数组更灵活，避免浪费内存或空间不足。
*   **结构体嵌套**：顺序表底层数组的类型不再是 `int`，而是自定义的 `Book` 结构体。这体现了**复合数据类型**的顺序存储。
*   **状态维护**：`int length` 是顺序表的核心属性，所有插入、删除、遍历操作都依赖于这个属性来确保数据的完整性。

### 💡 结合你“OOP建模”思维的跨语言重构

既然你在用 OOP 思想学数据结构，我们可以立刻把上面这段 C 代码，用 C++ 和 C# 的思想重构出来，彻底打通底层到上层的应用：

#### 🚀 C++ OOP 进阶实现 (动态内存 + RAII)
C++ 中我们通常用 `std::vector` 来代替手动的 `malloc/free`，自动处理扩容和内存释放。

```cpp
#include <vector>
#include <string>

// 1. 数据元素的类
struct Book {
    std::string no;      // 使用 string 代替 char 数组，避免溢出
    std::string name;
    float price;
};

// 2. 顺序表的类 (底层封装 vector)
class SqList {
private:
    std::vector<Book> elem;  // 动态数组，自动管理内存和扩容
    int length;

public:
    SqList() : length(0) {}

    // 添加图书（插入操作）
    void addBook(const Book& book) {
        elem.push_back(book); // vector 自动处理扩容
        length++;
    }

    // 获取当前长度
    int getLength() const {
        return length;
    }
};
```

#### 🚀 C# OOP 进阶实现 (属性封装 + 泛型集合)
C# 中使用 `List<T>` 作为底层，并使用属性（Property）封装数据。

```csharp
using System;
using System.Collections.Generic;

// 1. 数据元素的类
public class Book {
    public string No { get; set; }      // ISBN
    public string Name { get; set; }    // 书名
    public float Price { get; set; }    // 价格
}

// 2. 顺序表的类
public class SqList {
    private List<Book> elem;  // 底层动态顺序表

    public SqList() {
        elem = new List<Book>();
    }

    // 添加图书
    public void AddBook(Book book) {
        elem.Add(book); // 自动扩容，O(1) 均摊时间复杂度
    }

    // 暴露当前长度（只读属性）
    public int Length => elem.Count; 
}
```

**💬 这种对比的价值：**
通过这三种语言（C、C++、C#）的对比，你不仅学会了“顺序表”的定义，更深刻理解了**动态内存管理**、**泛型机制**以及**面向对象封装**在实现同一个底层数据结构时的不同表现形式。这对你整理系列专栏非常加分！

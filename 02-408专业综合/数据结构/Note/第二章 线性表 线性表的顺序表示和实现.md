## 2.4 线性表的顺序表示和实现
**线性表的存储结构**：线性表的顺序表示又称为 **顺序存储结构**或 **顺序映像**

**顺序存储定义** ： 把逻辑上相邻的数据元素存储在**物理上相邻**的存储单元中的存储结构。

**起始位置（基地址）** ： 线性表的第一个数据元素$a_1$的存储位置。

Q：数组与线性表的区别：

答案：线性表依次存储，地址连续——中间**没有空出存储单元**才是线性表顺序存储结构；
地址不连续——**中间存在空的存储单元**就不是线性表存储结构，数组中间可以有空的存储单元。

线性表顺序存储结构 **占用一片连续的存储空间**。知道某个元素的存储位置就可以计算其他元素的存储位置。

假设线性表的每个元素需要占$l$个存储单元，则第 $i+1$ 个数据元素的存储位置和第$i$个数据元素的存储位置之间满足关系：

$LOC(a_{i+1})=LOC(a_i)+l$

所有数据元素的存储位置可由第一个数据元素的存储位置得到

$LOC(a_i)=LOC(a_1)+（i-1）\times l$

顺序表的特点：以物理位置相邻表示逻辑关系。任意元素均可随机存取。（优点）

用一维数组表示顺序表，线性表长可变（增加或删除），数组长度不可动态定义=>用一变量表示顺序表长度属性
一维数组的定义方式：

**类型说明符** **数组名** **[常量表达式]**

说明：常量表达式可以包含常量和符号常量，不能包含变量。即C语言中不允许对数组的大小作动态定义。

**【案例背景】**
需要设计一个数据结构，用来存储和管理一组图书信息。
*   **数据元素**：每一本图书（包含ISBN、书名、价格）。
*   **数据结构**：由于图书表长度可变（可增删），且需要按顺序存取，采用**顺序存储结构（顺序表）**。

#### 1. 结构体定义（C语言伪代码提炼）

```c
#define MAXSIZE 10000  // 宏定义最大容量，防止溢出

// 1. 定义数据元素的结构体（单条图书信息）
typedef struct {
    char no[20];       // 图书ISBN（字符串）
    char name[50];     // 图书名字（字符串）
    float price;       // 图书价格（浮点数）
} Book;

// 2. 定义线性表的顺序存储结构（图书表）
typedef struct {
    Book *elem;        // 指向顺序表首地址的指针（动态分配内存空间）
    int length;        // 记录当前表中的实际图书个数

```

### 【算法2.3】顺序表的查找

*   **核心目标**：在线性表L中，查找与指定值 `e` 相同的数据元素。

### 顺序表的插入

*   **核心定义**：在线性表L的第 $i$ ($1 \le i \le n+1$) 个位置上，插入一个新结点 $e$，使长度为 $n$ 的表变成长度为 $n+1$ 的表。
*   **算法思想（5个步骤）**：
    1. **判断位置**：判断插入位置 $i$ 是否合法。
    2. **判断空间**：判断顺序表的存储空间是否已满，若已满返回 `ERROR`。
    3. **后移元素**：将第 $n$ 至第 $i$ 位的元素依次向后移动一个位置，空出第 $i$ 个位置。
    4. **放入新元**：将要插入的新元素 $e$ 放入第 $i$ 个位置。
    5. **表长加一**：表长加1，插入成功返回 `OK`。

这是为你提取的【算法2.4】顺序表插入的代码实现：

### 【算法2.4】顺序表的插入

```cpp
Status ListInsert_Sq(SqList &L, int i, ElemType e){
    // ① 判断位置i是否合法
    if (i < 1 || i > L.length + 1) return ERROR;  // i值不合法
    
    // ② 判断存储空间是否已满
    if (L.length == MAXSIZE) return ERROR;         // 当前存储空间已满
    
    // ③ 将第n至第i位的元素依次向后移动一个位置
    for (j = L.length - 1; j >= i - 1; j--)
        L.elem[j + 1] = L.elem[j];               // 插入位置及之后的元素后移
    
    // ④ 将新元素e放入第i个位置
    L.elem[i - 1] = e;                           // 将新元素e放入第i个位置
    
    // ⑤ 表长加1
    L.length++;                                  // 表长增1
    return OK;
}
```

### 顺序表的删除

*   **核心定义**：将表的第 $i$ ($1 \le i \le n$) 个结点删除，使长度为 $n$ 的表变成长度为 $n-1$ 的表。
*   **算法思想（4个步骤）**：
    1. **判断位置**：判断删除位置 $i$ 是否合法（合法值为 $1 \le i \le n$）。
    2. **保留元素**：将欲删除的元素保留在变量 `e` 中。
    3. **前移元素**：将第 $i+1$ 至第 $n$ 位的元素依次向前移动一个位置。
    4. **表长减一**：表长减1，删除成功返回 `OK`。

### 【算法2.5】顺序表的删除（代码实现）

```cpp
Status ListDelete_Sq(SqList &L, int i, ElemType &e){
    // ① 判断位置i是否合法
    if((i < 1) || (i > L.length)) return ERROR; // i值不合法
    
    // ② 保留欲删除的元素
    e = L.elem[i-1];
    
    // ③ 将被删除元素之后的元素依次前移
    for (int j = i; j <= L.length - 1; j++)
        L.elem[j-1] = L.elem[j];
        
    // ④ 表长减1
    L.length--;
    return OK;
}
```

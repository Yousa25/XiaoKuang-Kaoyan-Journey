**顺序存储结构**和**链式存储结构**

### 📚 核心知识点提炼

1. **核心概念**：线性表的顺序存储表示，又称为**顺序存储结构**或**顺序映像**。
2. **核心定义**：把**逻辑上相邻**的数据元素，存储在**物理上相邻**的存储单元中。
3. **逻辑结构**：线性表在逻辑上是一个有序的序列，表示为 $(a_1, a_2, \dots, a_{i-1}, a_i, a_{i+1}, \dots, a_n)$。

---

### 💡 易错点与注意点

*   **⚠️ 易错点：混淆“逻辑相邻”与“物理相邻”**
    *   **逻辑相邻**是指数据元素之间存在的先后次序关系（如截图中的公式所示，$a_{i-1}$ 的前一个就是 $a_i$）。
    *   **物理相邻**是指计算机内存地址上的紧挨着。
    *   **易错点在于**：在链式存储结构中，数据元素在逻辑上是相邻的，但在物理（内存）上**不一定**是相邻的。而顺序存储的核心特征恰恰就是要求两者**同时相邻**。

*   **⚠️ 易错点：忽视物理存储的“静态”限制**
    *   因为要求物理存储单元必须相邻，这就意味着在初始化顺序表时通常需要**预先分配一段连续的内存空间**。
    *   这导致了顺序表的**扩容**（增加空间）和**插入/删除**（移动元素）操作成本较高，这是后续学习中非常重要的考点。

*   **⚠️ 注意点：区分“存储结构”与“数据结构”**
    *   这里提到的“顺序存储结构”是一种**存储**方法（即数据在内存里怎么摆放），而“线性表”是一种**逻辑**上的数据结构（即数据之间有什么关系）。同一个线性表逻辑结构，既可以用顺序存储实现，也可以用链式存储实现。

## 2.4 线性表的顺序表示和实现
**线性表的存储结构**：线性表的顺序表示又称为 **顺序存储结构**或 **顺序映像**

**顺序存储定义** ： 把逻辑上相邻的数据元素存储在**物理上相邻**的存储单元中的存储结构。

**起始位置（基地址）** ： 线性表的第一个数据元素$a_1$的存储位置。

Q：数组与线性表的区别：

答案：线性表依次存储，地址连续——中间**没有空出存储单元**才是线性表顺序存储结构；
地址不连续——**中间存在空的存储单元**就不是线性表存储结构，数组中间可以有空的存储单元。

线性表顺序存储结构 **占用一片连续的存储空间**。知道某个元素的存储位置就可以计算其他元素的存储位置。

### 📚 核心知识点提炼

1. **典型实例（正确结构）**
   * 以线性表 $(1, 2, 3, 4, 5, 6)$ 为例，顺序存储结构要求数据元素在内存中**依次存储**，并且**地址是连续**的，中间**没有空出**的存储单元。
2. **非典型实例（错误结构）**
   * 如果在逻辑上相邻的元素（如2和3）之间出现了**地址不连续**（即中间存在空的存储单元），那么它就**不是**一个合法的线形表顺序存储结构。
3. **核心特征总结**
   * **占用一片连续的存储空间**。
   * **具备随机访问特性**：知道某个元素的存储位置，就可以直接计算出其他任意元素的存储位置。

---

### 💡 易错点与注意点

*   **⚠️ 易错点：忽视“连续性”的绝对要求**
   * 很多同学在做选择题或判断题时，容易把“逻辑上的有序”和“物理上的连续”割裂开。只要看到数据元素在内存地址上出现了跳跃（即**不连续**或**中间有空单元**），哪怕数据本身是对的，它也绝对不符合“顺序存储结构”的定义。
*   **⚠️ 易错点：混淆“随机访问”的实现原理**
   * 顺序存储结构之所以能实现“随机访问”（即通过下标 $O(1)$ 时间直接找到元素），完全依赖于它“占用一片连续的存储空间”。如果空间不连续，就必须顺着指针挨个找（即链式存储的查找方式），无法通过公式直接计算出位置。
*   **⚠️ 注意点：连续空间的物理本质**
   * 这里的“连续的存储空间”在计算机底层通常对应的是**数组**的内存模型。在编写代码实现顺序表时，必须确保使用的是支持连续内存分配的数据结构（如静态数组或动态数组）。

假设线性表的每个元素需要占$l$个存储单元，则第 $i+1$ 个数据元素的存储位置和第$i$个数据元素的存储位置之间满足关系：

$LOC(a_{i+1})=LOC(a_i)+l$

所有数据元素的存储位置可由第一个数据元素的存储位置得到

$LOC(a_i)=LOC(a_1)+（i-1）\times l$

顺序表的特点：以物理位置相邻表示逻辑关系。任意元素均可随机存取。（优点）

# 2.4.1 线性表的顺序存储表示（C语言定义）

## 一、 基础概念回顾
*   **逻辑结构到物理结构的映射**：逻辑上相邻的元素（$a_1, a_2, \dots$），在物理内存中也是相邻的。
*   **⚠️ 核心注意点（图中高亮）**：**逻辑位序和物理位序相差1**。
    *   逻辑上的第 $i$ 个元素，其在数组中的物理下标（索引）为 `i - 1`。

## 二、 顺序表的 C 语言结构体定义

在 C 语言中，顺序表通常包含三个关键部分：**数据元素、存储空间、表长度**。

### 1. 静态分配（基础版）
使用固定大小的数组来存储数据，编译时内存大小就已确定。
*   **代码示例**：
    ```c
    #define MAXSIZE 100 // 定义顺序表的最大容量
    typedef struct {
        ElemType elem[MAXSIZE]; // 静态数组，存放数据元素
        int length;             // 记录当前顺序表中实际元素的个数
    } SqList;
    ```
*   **特点**：`elem` 数组本身就在结构体内部，大小固定为 `MAXSIZE`，无法动态改变。

### 2. 动态分配（进阶版）
使用指针和动态内存分配函数，可以在程序运行时按需申请内存空间。
*   **代码示例**：
    ```c
    typedef struct {
        ElemType *elem; // 指向动态分配的数组首地址的指针
        int length;     // 记录当前顺序表中实际元素的个数
    } SqList;

    // 初始化/分配内存（使用malloc函数）
    // 假设 ElemType 为 int，这里申请了 MAXSIZE 个 int 空间
    L.elem = (ElemType*)malloc(sizeof(ElemType) * MAXSIZE);
    ```
*   **特点**：`elem` 是一个指针，指向堆区（Heap）的内存，空间大小可以动态调整，灵活性更高。

---

## 💡 易错点与避坑指南

1.  **静态数组与动态指针的区别**
    *   **易错点**：在写代码时，混淆静态数组定义 `ElemType elem[MAXSIZE]` 和动态指针定义 `ElemType *elem`。
    *   **避坑**：如果结构体内部是指针，**必须**在后续代码中使用 `malloc()` (或 `new` 在C++中) 为其在堆上分配内存，否则指针会成为野指针，导致程序崩溃。

2.  **`length` 的初始值**
    *   **易错点**：创建顺序表后，忘记将 `length` 初始化为 0，或者错误地初始化为 `MAXSIZE`。
    *   **避坑**：一个刚初始化、尚未存入数据的空表，其 `length` 绝对应该是 `0`。`MAXSIZE` 只是它的**最大容量**，而非当前长度。

3.  **逻辑位序与数组下标的越界问题**
    *   **易错点**：在遍历或操作顺序表时，循环条件写成 `i <= length` 导致数组越界（下标访问到 `length` 处，而最后一个有效元素的下标是 `length - 1`）。
    *   **避坑**：牢记循环遍历的条件应该是 `i < length`。

### 顺序表的插入

*   **核心定义**：在线性表L的第 $i$ ($1 \le i \le n+1$) 个位置上，插入一个新结点 $e$，使长度为 $n$ 的表变成长度为 $n+1$ 的表。
*   **算法思想（5个步骤）**：
    1. **判断位置**：判断插入位置 $i$ 是否合法。
    2. **判断空间**：判断顺序表的存储空间是否已满，若已满返回 `ERROR`。
    3. **后移元素**：将第 $n$ 至第 $i$ 位的元素依次向后移动一个位置，空出第 $i$ 个位置。
    4. **放入新元**：将要插入的新元素 $e$ 放入第 $i$ 个位置。
    5. **表长加一**：表长加1，插入成功返回 `OK`。

这是为你提取的【算法2.4】顺序表插入的代码实现：

### 【算法2.4】顺序表的插入

```cpp
Status ListInsert_Sq(SqList &L, int i, ElemType e){
    // ① 判断位置i是否合法
    if (i < 1 || i > L.length + 1) return ERROR;  // i值不合法
    
    // ② 判断存储空间是否已满
    if (L.length == MAXSIZE) return ERROR;         // 当前存储空间已满
    
    // ③ 将第n至第i位的元素依次向后移动一个位置
    for (j = L.length - 1; j >= i - 1; j--)
        L.elem[j + 1] = L.elem[j];               // 插入位置及之后的元素后移
    
    // ④ 将新元素e放入第i个位置
    L.elem[i - 1] = e;                           // 将新元素e放入第i个位置
    
    // ⑤ 表长加1
    L.length++;                                  // 表长增1
    return OK;
}
```

### 顺序表的删除

*   **核心定义**：将表的第 $i$ ($1 \le i \le n$) 个结点删除，使长度为 $n$ 的表变成长度为 $n-1$ 的表。
*   **算法思想（4个步骤）**：
    1. **判断位置**：判断删除位置 $i$ 是否合法（合法值为 $1 \le i \le n$）。
    2. **保留元素**：将欲删除的元素保留在变量 `e` 中。
    3. **前移元素**：将第 $i+1$ 至第 $n$ 位的元素依次向前移动一个位置。
    4. **表长减一**：表长减1，删除成功返回 `OK`。

### 【算法2.5】顺序表的删除（代码实现）

```cpp
Status ListDelete_Sq(SqList &L, int i, ElemType &e){
    // ① 判断位置i是否合法
    if((i < 1) || (i > L.length)) return ERROR; // i值不合法
    
    // ② 保留欲删除的元素
    e = L.elem[i-1];
    
    // ③ 将被删除元素之后的元素依次前移
    for (int j = i; j <= L.length - 1; j++)
        L.elem[j-1] = L.elem[j];
        
    // ④ 表长减1
    L.length--;
    return OK;
}
```

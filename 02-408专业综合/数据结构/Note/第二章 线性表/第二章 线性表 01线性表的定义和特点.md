## 2.1 线性表的定义和特点

**线性表**：具有相同特性的数据元素的一个有限序列 $(a_1, a_2, ..., a_{i-1}, a_i, a_{i+1}, ..., a_n)$

- 由 $n$ ($n \ge 0$) 个数据元素组成的有限序列。
- 其中数据元素的个数 $n$ 定义为表的长度。
- 当 $n=0$ 时称为空表。
- 将非空的线性表 ($n>0$) 记作 $(a_1, a_2, ..., a_n)$。
- 数据元素 $a_i$ 是一个抽象符号，具体含义在不同情况下可以不同。

> **核心特性**：同一线性表中的元素必定具有相同特性，数据元素间的关系是线性关系。

### 线性表的逻辑特征

- 在非空的线性表中，有且仅有一个**开始结点** $a_1$，它没有**直接前趋**，而仅有一个**直接后继** $a_2$。
- 有且仅有一个**终端结点** $a_n$，它没有**直接后继**，而仅有一个**直接前趋** $a_{n-1}$。
- 其余的**内部结点** $a_i$ ($2 \le i \le n-1$) 都有且仅有一个**直接前趋** $a_{i-1}$ 和一个**直接后继** $a_{i+1}$。

## 2.2 案例引入

### 案例一：一元多项式的运算
实现两个多项式加减乘运算：系数的下标隐含表示指数，系数用数组实现的线性表。
- 如果多个多项式相加，只需要将下标相同的系数进行操作即可。
- 对于稀疏多项式用数组浪费空间，把不为0的用二元组存储即可，$(x, y)$ 中 $x$ 为系数，$y$ 为指数存为一个数组即可。运算时使用新数组 $C$，指数小的放前面，一样的进行计算。

这张图片展示的是**稀疏多项式的加法运算**，使用的是**三元组顺序表（即数组）**来存储数据。

以下是结合图片内容的核心知识点提炼：

### 1. 什么是稀疏多项式的存储？
稀疏多项式是指绝大多数系数都为0的多项式。为了节省空间，我们只存储**非零项**。
图片中采用的三元组形式为：**(系数, 指数)**。
*   **线性表A** 代表多项式：$7x^0 + 3x^1 + 9x^8 + 5x^{17}$
*   **线性表B** 代表多项式：$8x^1 + 22x^7 - 9x^8$

### 2. 运算逻辑（模拟双指针归并排序）
将多项式A和B相加得到多项式C，核心逻辑是**分别从头遍历比较A和B的每一项**：
*   **情况一：指数相同**
    *   **操作**：对应系数相加。
    *   **判断**：若相加后的和**不为零**，则在C中增加一个新项（存入新系数和该指数）。若和为零，则该项抵消，不存入C。
*   **情况二：指数不同**
    *   **操作**：将**指数较小**的那一项直接复制到C中。
    *   *(注：因为多项式通常是按指数递增或递减顺序排列的，这里假设是递增)*

*   **收尾工作**：
    *   当一个多项式（A或B）遍历完毕后，将另一个多项式**剩余的项**依次复制到C中即可。

### 3. 图中留下的思考点：数组C到底该开辟多大？
图片右下角提出了一个经典问题：“数组c多大合适呢？”

在实际编程和数据结构设计中，这是一个需要考虑内存分配的问题：
*   **理论最大值**：C的长度最多为 A的长度 + B的长度（当A和B没有任何相同指数的项，且相加都不为0时）。
*   **实际情况**：C的长度 $\le$ A的长度 + B的长度（因为可能会有指数相同的项合并，甚至抵消为0）。
*   **解决方案**：在实际代码实现中，如果要求精确控制空间，通常采用**动态数组**（如C++的`std::vector`或Java的`ArrayList`），不需要预先指定固定大小，而是随着结果的产生动态地`push_back`新元素。

这是一个使用 C++ 实现的稀疏多项式加法运算代码。

### 核心思路
根据图片中的逻辑，我们采用“双指针法”：
1.  **定义结构体**：使用 `Term` 结构体存储多项式的每一项（系数 `coef` 和指数 `exp`）。
2.  **双指针遍历**：分别用两个指针（索引）`i` 和 `j` 指向多项式 A 和 B 的当前项。
3.  **比较与合并**：
    *   若 A 的指数 < B 的指数：将 A 的当前项加入 C，A 的指针后移。
    *   若 A 的指数 > B 的指数：将 B 的当前项加入 C，B 的指针后移。
    *   若 A 的指数 == B 的指数：系数相加。如果和不为 0，则生成新项加入 C；如果和为 0，则抵消（不加入）。两个指针同时后移。
4.  **处理剩余项**：当其中一个多项式遍历完后，将另一个多项式剩余的项直接拷贝到 C 中。

### C++ 代码实现

```cpp
#include <iostream>
#include <vector>

using namespace std;

// 定义多项式的项结构体
struct Term {
    int coef; // 系数 (Coefficient)
    int exp;  // 指数 (Exponent)

    Term(int c, int e) : coef(c), exp(e) {}
};

// 打印多项式的辅助函数
void printPoly(const vector<Term>& poly, const string& name) {
    cout << name << " = ";
    for (int i = 0; i < poly.size(); ++i) {
        if (i > 0 && poly[i].coef > 0) cout << " + ";
        cout << poly[i].coef << "x^" << poly[i].exp;
    }
    cout << endl;
}

// 稀疏多项式相加函数
vector<Term> addPolynomials(const vector<Term>& A, const vector<Term>& B) {
    vector<Term> C; // 结果数组 C
    int i = 0, j = 0; // 分别指向 A 和 B 的当前项

    // 1. 分别从从头遍历比较 A 和 B 的每一项
    while (i < A.size() && j < B.size()) {
        if (A[i].exp < B[j].exp) {
            // 情况：指数不相同，将指数较小的项复制到 C 中
            C.push_back(A[i]);
            i++;
        } else if (A[i].exp > B[j].exp) {
            // 情况：指数不相同，将指数较小的项复制到 C 中
            C.push_back(B[j]);
            j++;
        } else {
            // 情况：指数相同，对应系数相加
            int sumCoef = A[i].coef + B[j].coef;
            if (sumCoef != 0) {
                // 若其和不为零，则在 C 中增加一个新项
                C.push_back(Term(sumCoef, A[i].exp));
            }
            // 无论是否为零，A 和 B 的指针都要后移
            i++;
            j++;
        }
    }

    // 2. 一个多项式已遍历完毕时，将另一个剩余项依次复制到 C 中
    while (i < A.size()) {
        C.push_back(A[i]);
        i++;
    }
    while (j < B.size()) {
        C.push_back(B[j]);
        j++;
    }

    return C;
}

int main() {
    // 初始化图片中的线性表 A 和 B
    // 线性表 A = ((7, 0), (3, 1), (9, 8), (5, 17))
    vector<Term> A = {{7, 0}, {3, 1}, {9, 8}, {5, 17}};

    // 线性表 B = ((8, 1), (22, 7), (-9, 8))
    vector<Term> B = {{8, 1}, {22, 7}, {-9, 8}};

    printPoly(A, "A");
    printPoly(B, "B");

    // 执行加法运算
    vector<Term> C = addPolynomials(A, B);

    printPoly(C, "C");

    return 0;
}
```

### 运行结果预期
根据图片中的数据逻辑，程序的输出应该是：
```text
A = 7x^0 + 3x^1 + 9x^8 + 5x^17
B = 8x^1 + 22x^7 - 9x^8
C = 7x^0 + 11x^1 + 22x^7 + 5x^17
```

### 关于图片中问题的解答：“数组 C 多大合适呢？”
在上面的 C++ 代码中，我使用了 `std::vector`。这完美解决了图片右下角提出的内存分配问题：
- **动态扩容**：`vector` 是动态数组，不需要预先知道确切大小。它会在 `push_back` 时自动管理内存。
- **理论最大值**：如果非要预先分配固定大小的数组（例如在纯 C 语言或嵌入式环境中），数组 C 的最大长度应该是 **A 的长度 + B 的长度**。这种情况发生在 A 和 B 没有任何相同指数的项时。

> **总结**：顺序存储结构存在问题，存储空间分配不灵活，运算的空间复杂度高。因此可用**链式存储结构**。
以下是结合图片的核心知识点解析：

### 1. 数据结构：链表节点
图中的方块代表链表的节点，每个节点存储了多项式的一项，格式为：**(系数, 指数, 指针域)**。
*   **多项式 A**：$7x^0 + 11x^1 + 9x^8 + 5x^{17}$ (注意：图中 $x^1$ 的系数被更新为了 11)
*   **多项式 B**：$8x^1 + 22x^7 - 9x^8$

### 2. 核心逻辑：双指针归并
使用两个指针 `pa`（指向 A 的当前节点）和 `pb`（指向 B 的当前节点），依次比较指数的大小。
*   **图中正在进行的操作**：
    图中高亮的绿色节点和红线表明，当前 `pa` 指向 A 的 **(11, 1)**，`pb` 指向 B 的 **(22, 7)**。
*   **指数不相同时的处理**：
    因为 $1 < 7$（A 的指数较小），所以将 `pa` 指向的节点 $(11, 1)$ 保留（或复制）到结果多项式 C 中。随后，指针 `pa` 后移指向 $(9, 8)$，而指针 `pb` 保持不动，继续与 A 的下一项进行比较。

### 3. 链表实现 vs 数组实现的区别
*   **内存开销**：链表实现需要额外的空间来存储指针域（图中的第三格），比数组稍微浪费空间。
*   **增删操作**：链表在中间插入或删除节点时，只需要修改指针指向，**不需要像数组那样移动大量元素**，理论上效率更高。
*   **动态性**：链表不需要像数组那样预先考虑容量问题，可以随时创建新节点。

简单来说，这张图就是**用链表的“指针指来指去”，代替了数组的“下标 i 和 j 往后挪”**，来完成两个多项式的相加。

这张图片是对前面所学内容的**理论升华和总结**。它解释了我们为什么在数据结构课中总是先讲“逻辑结构”，再讲“存储结构”。

以下是这段总结的通俗解读：

### 1. 线性表的包容性（第一点）
线性表并不只是简单的整数或字符列表。它里面存放的“数据元素”，既可以是像 `int` 这样的**简单类型**，也可以是像我们前面学的**稀疏多项式节点**（系数+指数）这样的**复杂类型**。只要它们具有“一对一”的线性关系，就属于线性表。

### 2. 为什么要抽象出“逻辑结构”？（第二点、第三点）
这是数据结构的精髓所在。
*   **拒绝重复造轮子**：很多实际问题的底层操作其实是一样的。比如“多项式相加”和“排队买票”，底层逻辑都是“线性表”，都需要“遍历、插入、查找”等基本操作。如果每次遇到新问题都单独写一套代码，效率极低。
*   **设计与实现分离**：
    1.  **逻辑设计阶段**：我们先不管数据在内存里怎么放，只抽象出它们的关系（线性关系）和基本操作（定义一个**抽象数据类型 ADT**）。这就像是先画一张“建筑蓝图”。
    2.  **物理实现阶段**：有了蓝图之后，我们再去考虑具体的存储方式。是像数组那样用**顺序存储**连续放？还是像多项式那样用**链式存储**散开放？这就是“实现其存储结构和基本操作”。

**一句话总结这段话的核心思想：**
先通过**抽象**找到问题的共性（逻辑结构/ADT），然后再根据实际需求选择具体的**实现方式**（存储结构），从而写出通用、可复用的代码。

下面我用 C# 泛型写一段代码，演示如何把“逻辑设计”落地成接口代码。这段代码完全不关心数据具体是整数、字符串还是多项式节点，也不关心底层是用数组还是链表，只关心“它必须提供哪些功能”。

### 1. 定义线性表的抽象数据类型（ADT）
```csharp
/// <summary>
/// 线性表的抽象数据类型（ADT）定义
/// T 是泛型类型参数，代表数据元素（可以是 int, string, 或者自定义的复杂对象）
/// </summary>
/// <typeparam name="T">数据元素的类型</typeparam>
public interface IList<T>
{
    // 基本操作接口定义

    /// <summary>
    /// 在指定索引位置插入一个元素（逻辑：增）
    /// </summary>
    void Insert(int index, T item);

    /// <summary>
    /// 删除指定索引位置的元素（逻辑：删）
    /// </summary>
    void Delete(int index);

    /// <summary>
    /// 获取或修改指定索引位置的元素（逻辑：查/改）
    /// </summary>
    T this[int index] { get; set; }

    /// <summary>
    /// 获取线性表当前的元素个数
    /// </summary>
    int Count { get; }
}
```

*   底层用**数组**实现的，就是顺序表（比如 .NET 官方的 `List<T>`）：
    ```csharp

    public class ArrayList<T> : IList<T> 
    {
        private T[] _items;

            // 逻辑：如果数组满了，先扩容2倍，然后把后面的元素往后移...
    ```

## 2.3 线性表的类型定义

### 抽象数据类型（ADT）定义

```text
ADT List {
    数据对象：D = {a_i | a_i ∈ ElemSet, (i = 1, 2, ..., n, n ≥ 0)}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, (i = 2, 3, ..., n)}
    基本操作：
        InitList(&L);              DestroyList(&L);
        ListInsert(&L, i, e);      ListDelete(&L, i, &e);
        ......等等
} ADT List
```

### 基本操作详解

#### 1. 创建与销毁
- **InitList(&L)** (Initialization List)
  - **操作结果**：构造一个空的线性表 $L$。
- **DestroyList(&L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：销毁线性表 $L$。
- **ClearList(&L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：将线性表 $L$ 重置为空表。

#### 2. 状态查询
- **ListEmpty(L)**
  - **初始条件**：线性表 $L$ 已经存在 ($n = 0$)。
  - **操作结果**：若线性表 $L$ 为空表，则返回 `TRUE`；否则返回 `FALSE`。
- **ListLength(L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：返回线性表 $L$ 中的数据元素个数 ($n$)。

#### 3. 数据访问与定位
- **GetElem(L, i, &e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)}$。
  - **操作结果**：用 $e$ 返回线性表 $L$ 中第 $i$ 个数据元素的值。
- **LocateElem(L, e, compare())**
  - **初始条件**：线性表 $L$ 已经存在，`compare()` 是数据元素判定函数。
  - **操作结果**：返回 $L$ 中第 $1$ 个与 $e$ 满足 `compare()` 的数据元素的位序。若这样的数据元素不存在则返回值为 $0$。
- **PriorElem(L, cur_e, &pre_e)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：若 `cur_e` 是 $L$ 的数据元素，且不是第一个，则用 `pre_e` 返回它的前驱；否则操作失败，`pre_e` 无意义。
- **NextElem(L, cur_e, &next_e)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：若 `cur_e` 是 $L$ 的数据元素，且不是最后一个，则用 `next_e` 返回它的后继；否则操作失败，`next_e` 无意义。

#### 4. 插入与删除
- **ListInsert(&L, i, e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)} + 1$。
  - **操作结果**：在 $L$ 的第 $i$ 个位置之前插入新的数据元素 $e$，$L$ 的长度加一。
    - 插入前（长度为 $n$）：$(a_1, a_2, ..., a_{i-1}, a_i, ..., a_n)$
    - 插入后（长度为 $n+1$）：$(a_1, a_2, ..., a_{i-1}, \textbf{e}, a_i, ..., a_n)$
- **ListDelete(&L, i, &e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)}$。
  - **操作结果**：删除 $L$ 的第 $i$ 个数据元素，并用 $e$ 返回其值，$L$ 的长度减一。
    - 删除前（长度为 $n$）：$(a_1, a_2, ..., a_{i-1}, a_i, a_{i+1}, ..., a_n)$
    - 删除后（长度为 $n-1$）：$(a_1, a_2, ..., a_{i-1}, a_{i+1}, ..., a_n)$

#### 5. 遍历
- **ListTraverse(&L, visited())**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：依次对线性表中每个元素调用 `visited()`。

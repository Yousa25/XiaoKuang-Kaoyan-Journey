## 3.反函数和复合函数


这张图片是关于**反函数**的数学笔记，我来为你整理一下其中的核心知识点：

### 1. 反函数的定义
*   **前提**：设函数 $y = f(x)$ 的定义域为 $D$，值域为 $R_y$。
*   **条件**：如果对值域中的任意一个 $y$，在定义域 $D$ 中都有**唯一确定**的 $x$ 与之对应（即满足 $y = f(x)$）。
*   **结果**：那么这个 $x$ 就是 $y$ 的函数，记为 $x = f^{-1}(y)$。这个函数被称为原函数的**反函数**。

### 2. 实例理解（手写部分）
*   **原函数**：$y = x^3$
*   **反解过程**：将 $x$ 和 $y$ 的位置互换求解，得到 $x = y^{\frac{1}{3}}$。
*   **反函数表达**：
    *   写作 $x$ 的函数：$y = f^{-1}(x) = x^{\frac{1}{3}}$
    *   写作 $y$ 的函数：$x = y^3 \Rightarrow y = x^{\frac{1}{3}}$ (这里手写笔记展示了变量互换的过程)。

### 3. 核心性质与几何意义
*   **对称性**：函数 $y = f(x)$ 与其反函数 $y = f^{-1}(x)$ 的图像**关于直线 $y = x$ 对称**。
*   **坐标关系**：如果原函数图像上有一个点 $P(a, b)$，那么其反函数图像上一定对应有一个点 $Q(b, a)$。
*   **垂直平分**：连接点 $P$ 和点 $Q$ 的线段，会被直线 $y = x$ 垂直平分（如图中虚线所示）。

### 复合函数

### 复合函数概念提取

#### 1. 定义
设 $y = f(u)$ 的定义域为 $D_f$，$u = g(x)$ 的定义域为 $D_g$，值域为 $R_g$。若 $D_f \cap R_g \neq \emptyset$，则称函数 $y = f[g(x)]$ 为函数 $y = f(u)$ 与 $u = g(x)$ 的复合函数。

它的定义域为：
$$ \{ x \mid x \in D_g, g(x) \in D_f \} $$

#### 2. 例题分析
已知分段函数：
$$ g(x) = \begin{cases} 2 - x, & x \le 0 \\ x + 2, & x > 0 \end{cases} $$
$$ f(x) = \begin{cases} x^2, & x < 0 \\ -x, & x \ge 0 \end{cases} $$

求 $g[f(x)]$ 及 $f[g(x)]$。

---

### 要注意的点和易错点

#### 1. 复合函数的构成条件
- **核心条件**：内层函数的值域（或其一部分）必须落在外层函数的定义域内。即 $g(x)$ 的输出值（$u$）必须满足 $f(u)$ 的定义要求。
- **定义域**：复合函数 $y = f[g(x)]$ 的定义域，是使得 $x \in D_g$ 且 $g(x) \in D_f$ 的 $x$ 的集合。

#### 2. 分段函数复合的“代入规则”
- 复合时，是将**内层函数的整体**作为**外层函数的自变量**，去判断它属于外层函数定义域的哪一段。
- 例如求 $g[f(x)]$：
  - 外层是 $g(u)$，分段点是 $u \le 0$ 和 $u > 0$。
  - 这里的 $u = f(x)$，所以需要根据 $f(x) \le 0$ 还是 $f(x) > 0$ 来决定代入 $g$ 的哪一段。
- 求 $f[g(x)]$：
  - 外层是 $f(u)$，分段点是 $u < 0$ 和 $u \ge 0$。
  - 这里的 $u = g(x)$，所以需要根据 $g(x) < 0$ 还是 $g(x) \ge 0$ 来决定代入 $f$ 的哪一段。

#### 3. 易错点：分段条件的转化
- 在确定 $f(x)$ 的符号（或 $g(x)$ 的符号）时，必须结合 $f(x)$（或 $g(x)$）自身的分段定义来解不等式。
- 例如 $f(x) = \begin{cases} x^2, & x < 0 \\ -x, & x \ge 0 \end{cases}$，$x^2$ 在 $x < 0$ 时恒大于 $0$；$-x$ 在 $x \ge 0$ 时恒小于等于 $0$。
- 所以 $f(x) < 0$ 仅当 $x > 0$ 时（此时 $f(x) = -x < 0$）；$f(x) \ge 0$ 当 $x < 0$（$x^2 > 0$）或 $x = 0$（$-x = 0$）时。

#### 4. 边界值的归属
- 注意分段点（如 $0$）在不等式中的归属（$\le$ 还是 $<$），代入时不能搞错。

### 练习题巩固

#### 练习 1：基础复合
已知 $f(x) = \begin{cases} x + 1, & x \ge 0 \\ x^2, & x < 0 \end{cases}$，求 $f[f(x)]$。

**提示**：
- 外层分段点为 $u \ge 0$ 和 $u < 0$，内层 $u = f(x)$。
- 需先分析 $f(x) \ge 0$ 和 $f(x) < 0$ 分别对应 $x$ 的哪些范围。

#### 练习 2：求定义域
已知 $f(x)$ 的定义域为 $[1, 5]$，求 $f(2x - 1)$ 的定义域。

**提示**：
- 内层 $u = 2x - 1$ 必须满足 $u \in [1, 5]$，即 $1 \le 2x - 1 \le 5$。

#### 练习 3：综合分段
已知 $f(x) = \begin{cases} 2x, & x > 0 \\ x + 1, & x \le 0 \end{cases}$，$g(x) = \begin{cases} x^2, & x \in \mathbb{Q} \\ -x, & x \notin \mathbb{Q} \end{Q}$ （$\mathbb{Q}$ 为有理数集）。
求 $f[g(\sqrt{2})]$ 和 $f[g(2)]$。

**提示**：
- 先根据自变量是有理数还是无理数确定 $g(x)$ 的值，再代入 $f$。

---

### 练习题简要解答

#### 练习 1 解答：
- $f(x) = \begin{cases} x + 1, & x \ge 0 \\ x^2, & x < 0 \end{cases}$。
- 当 $x \ge 0$ 时，$f(x) = x + 1 \ge 1 \ge 0$，所以 $f[f(x)] = f(x + 1) = (x + 1) + 1 = x + 2$。
- 当 $x < 0$ 时，$f(x) = x^2 > 0$（$x \neq 0$），所以 $f(x) \ge 0$ 恒成立。代入 $f$ 的 $u \ge 0$ 段：$f[f(x)] = f(x^2) = x^2 + 1$。
- 结果：$f[f(x)] = \begin{cases} x + 2, & x \ge 0 \\ x^2 + 1, & x < 0 \end{cases}$。

#### 练习 2 解答：
- $1 \le 2x - 1 \le 5 \implies 2 \le 2x \le 6 \implies 1 \le x \le 3$。定义域为 $[1, 3]$。

#### 练习 3 解答：
- $\sqrt{2}$ 是无理数，$g(\sqrt{2}) = -\sqrt{2} < 0$，则 $f[-\sqrt{2}] = -\sqrt{2} + 1$。
- $2$ 是有理数，$g(2) = 2^2 = 4 > 0$，则 $f[4] = 2 \times 4 = 8$。

## 4.函数的运算

### 1. 概念提取：函数的运算与分解

#### 函数的四则运算
设函数 $f(x)$ 和 $g(x)$ 的定义域分别为 $D_f$ 和 $D_g$，且 $D_f \cap D_g \neq \emptyset$。

- **加法/减法**：$(f \pm g)(x) = f(x) \pm g(x)$
- **乘法**：$(f \cdot g)(x) = f(x) \cdot g(x)$
- **除法**：$\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}$，其中需满足 $g(x) \neq 0$

#### 【例6】重要结论：任意函数的奇偶分解
**命题**：设函数 $f(x)$ 的定义域为 $(-l, l)$（关于原点对称），则必存在 $(-l, l)$ 上的偶函数 $g(x)$ 及奇函数 $h(x)$，使得 $f(x) = g(x) + h(x)$。

**构造公式**（即图中的推导结果）：
- **偶部**：$g(x) = \frac{1}{2}[f(x) + f(-x)]$
- **奇部**：$h(x) = \frac{1}{2}[f(x) - f(-x)]$

---

### 2. 为什么武忠祥老师说这个结论很重要？

这个结论之所以在考研数学中地位极高，是因为它揭示了**函数结构的本质**，并在解题中提供了“降维打击”的工具。

#### 重要性体现：
1.  **化繁为简（解题神器）**：
    很多复杂的函数看起来既不是奇函数也不是偶函数，直接积分或求导很困难。利用这个结论，可以将其拆分为“奇函数部分”和“偶函数部分”。
    -   **对称区间积分**：$\int_{-a}^{a} f(x) dx = \int_{-a}^{a} [g(x) + h(x)] dx = \int_{-a}^{a} g(x) dx + 0 = 2\int_{0}^{a} g(x) dx$。这能瞬间消除掉复杂的奇函数项。
    -   **泰勒展开**：偶函数的展开式只含偶次幂，奇函数只含奇次幂。判断系数是否为0时非常有用。

2.  **唯一性证明**：
    这种分解是**唯一**的。这意味着如果你能把一个函数凑成“偶+奇”的形式，那它就是唯一的分解形式。这在证明题中常作为理论支撑。

3.  **构造反例或特例**：
    在分析函数性质时，可以通过分别研究奇部和偶部的性质来推断原函数的性质。

---

### 3. 要注意的点和易错点

#### 注意点
- **定义域前提**：必须强调定义域关于原点对称（如 $(-l, l)$），否则 $f(-x)$ 无意义，奇偶性无从谈起。
- **运算封闭性**：
    -   偶 $\pm$ 偶 = 偶
    -   奇 $\pm$ 奇 = 奇
    -   奇 $\times$ 奇 = 偶
    -   偶 $\times$ 偶 = 偶
    -   奇 $\times$ 偶 = 奇

#### 易错点
- **除法运算的定义域**：做 $\frac{f}{g}$ 运算时，不仅要求 $x$ 在 $f$ 和 $g$ 的公共定义域内，还必须剔除使 $g(x)=0$ 的点。
- **混淆分解公式**：
    -   记反符号：$g(x)$ (偶) 是加号，$h(x)$ (奇) 是减号。
    -   **记忆口诀**：“偶加奇减”。因为 $f(x)+f(-x)$ 把相反的部分抵消了，留下了相同的部分（偶）；$f(x)-f(-x)$ 把相同的部分抵消了，留下了相反的部分（奇）。
- **忽视常数项**：常数函数（非零）是偶函数。在分解时，常数项归属于 $g(x)$。

### 4. 巩固练习题

#### 基础练习（概念理解）
1.  设 $f(x) = x^3 + x^2 + x + 1$，请将其分解为偶函数 $g(x)$ 和奇函数 $h(x)$ 的和。

#### 进阶练习（武忠祥风格应用）

    *提示：利用奇偶分解思想，观察各项的奇偶性。*

4.  **（抽象函数性质）**：设 $f(x)$ 定义在 $(-l, l)$ 上，且 $f(x) = g(x) + h(x)$，其中 $g(x)$ 为偶函数，$h(x)$ 为奇函数。若已知 $f(x) = e^x$，求 $h(x)$ 的表达式。
    *提示：直接使用图中的结论公式。*

### 练习题参考答案与解析

**1. 解：**
根据公式：
$g(x) = \frac{1}{2}[f(x) + f(-x)] = \frac{1}{2}[(x^3+x^2+x+1) + (-x^3+x^2-x+1)] = x^2 + 1$ （偶函数）
$h(x) = \frac{1}{2}[f(x) - f(-x)] = \frac{1}{2}[(x^3+x^2+x+1) - (-x^3+x^2-x+1)] = x^3 + x$ （奇函数）
验证：$(x^2+1) + (x^3+x) = x^3+x^2+x+1$，正确。

**2. 解：**
令 $F(x) = f(x) - f(-x)$。
$F(-x) = f(-x) - f(-(-x)) = f(-x) - f(x) = -[f(x) - f(-x)] = -F(x)$。
所以 $F(x)$ 是**奇函数**。
*(注：其实这就是 $2h(x)$，即两倍的奇部)*

**3. 解：**
被积函数可以看作几项之和：
- $y_1 = x^5 \cos x$：奇 $\times$ 偶 = 奇。在 $[-1, 1]$ 上积分为 0。
- $y_2 = x^2 \sin x$：偶 $\times$ 奇 = 奇。在 $[-1, 1]$ 上积分为 0。
- $y_3 = x^2 + 1$：偶函数。
所以 $I = 0 + 0 + \int_{-1}^{1} (x^2+1) dx = 2\int_{0}^{1} (x^2+1) dx = 2[\frac{x^3}{3} + x]_0^1 = 2(\frac{1}{3} + 1) = \frac{8}{3}$。

**4. 解：**
题目要求 $h(x)$，即求 $f(x)=e^x$ 的奇部。
直接套用公式：
$h(x) = \frac{1}{2}[f(x) - f(-x)] = \frac{1}{2}(e^x - e^{-x})$。
*(注：这就是双曲正弦函数 $\sinh x$)*

## 5.初等函数

这张图片是关于**初等函数**的数学笔记，涵盖了基本初等函数的分类以及初等函数的定义。以下是核心知识点的整理、易错点分析以及针对性的练习题。

### 核心概念提取

#### 1. 五类基本初等函数
这是构成所有复杂函数的“积木”，必须熟练掌握它们的图像和性质：
- **幂函数**：$y = x^\mu$ （$\mu$ 为实数）。例如 $y=x, y=x^2, y=\sqrt{x}, y=\frac{1}{x}$。
- **指数函数**：$y = a^x$ （$a > 0, a \neq 1$）。图像过点 $(0,1)$，单调性取决于 $a$ 的大小。
- **对数函数**：$y = \log_a x$ （$a > 0, a \neq 1$）。图像过点 $(1,0)$，定义域为 $(0, +\infty)$。
- **三角函数**：$y = \sin x, y = \cos x, y = \tan x, y = \cot x$。具有周期性。
- **反三角函数**：$y = \arcsin x, y = \arccos x, y = \arctan x, y = \text{arccot } x$。是三角函数的反函数，有特定的值域限制（如 $\arctan x$ 的值域是 $(-\frac{\pi}{2}, \frac{\pi}{2})$）。

#### 2. 初等函数的定义
由**常数**和**基本初等函数**经过**有限次**的**加、减、乘、除**和**复合**运算所得到的，且能用**一个解析式**表示的函数，称为初等函数。

---

### ⚠️ 要注意的点和易错点

1.  **“有限次”运算**：
    -   初等函数必须是经过有限次运算得到的。像狄利克雷函数 $D(x)$（有理数取1，无理数取0）虽然也是函数，但它无法用有限次四则运算或复合表示，因此**不是**初等函数。
    -   分段函数通常**不是**初等函数（除非能化简为一个统一的解析式，如 $y=|x|=\sqrt{x^2}$ 是初等函数）。

2.  **定义域的陷阱**：
    -   **对数函数**：真数必须大于0。例如 $\log_2(x-1)$ 要求 $x>1$。
    -   **偶次根式**：被开方数必须非负。例如 $\sqrt{x}$ 要求 $x \ge 0$。
    -   **反三角函数**：$\arcsin x$ 和 $\arccos x$ 的定义域严格限制在 $[-1, 1]$，而 $\arctan x$ 的定义域是全体实数。

3.  **底数的限制**：
    -   指数函数和对数函数的底数 $a$ 必须满足 $a>0$ 且 $a \neq 1$。如果题目中出现参数 $a$，一定要讨论这个范围。

4.  **反三角函数的值域**：
    -   这是最容易混淆的地方。$\arcsin x$ 的值域是 $[-\frac{\pi}{2}, \frac{\pi}{2}]$，而 $\arccos x$ 的值域是 $[0, \pi]$。在做求值或解方程题目时，必须注意结果是否落在主值区间内。

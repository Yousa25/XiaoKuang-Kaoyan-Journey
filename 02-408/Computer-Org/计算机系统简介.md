# 1.1 计算机系统简介

## 一、 计算机系统

计算机系统分为硬件和软件。


``` mermaid 
graph 

A(计算机系统) --- B(硬件：计算机的实体，如主机、外设等)
A(计算机系统) --- c(软件：由具有各类特殊功能的信息（程序组成）)
```
---

``` mermaid 
graph 
    A[软件] ---B("系统软件:用来管理整个计算机系统") --- C[语言处理程序]
    B---D[操作系统]
    B---E[服务型程序]
    B---F[数据库管理系统]
    B---H[网络软件]
    A----I[应用软件:按任务需要编制成各种程序]
```

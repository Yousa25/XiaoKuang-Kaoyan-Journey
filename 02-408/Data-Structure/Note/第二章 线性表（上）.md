## 2.1 线性表的定义和特点

**线性表**：具有相同特性的数据元素的一个有限序列 $(a_1, a_2, ..., a_{i-1}, a_i, a_{i+1}, ..., a_n)$

- 由 $n$ ($n \ge 0$) 个数据元素组成的有限序列。
- 其中数据元素的个数 $n$ 定义为表的长度。
- 当 $n=0$ 时称为空表。
- 将非空的线性表 ($n>0$) 记作 $(a_1, a_2, ..., a_n)$。
- 数据元素 $a_i$ 是一个抽象符号，具体含义在不同情况下可以不同。

> **核心特性**：同一线性表中的元素必定具有相同特性，数据元素间的关系是线性关系。

### 线性表的逻辑特征

- 在非空的线性表中，有且仅有一个**开始结点** $a_1$，它没有**直接前趋**，而仅有一个**直接后继** $a_2$。
- 有且仅有一个**终端结点** $a_n$，它没有**直接后继**，而仅有一个**直接前趋** $a_{n-1}$。
- 其余的**内部结点** $a_i$ ($2 \le i \le n-1$) 都有且仅有一个**直接前趋** $a_{i-1}$ 和一个**直接后继** $a_{i+1}$。

## 2.2 案例引入

### 案例一：一元多项式的运算
实现两个多项式加减乘运算：系数的下标隐含表示指数，系数用数组实现的线性表。
- 如果多个多项式相加，只需要将下标相同的系数进行操作即可。
- 对于稀疏多项式用数组浪费空间，把不为0的用二元组存储即可，$(x, y)$ 中 $x$ 为系数，$y$ 为指数存为一个数组即可。运算时使用新数组 $C$，指数小的放前面，一样的进行计算。

> **总结**：顺序存储结构存在问题，存储空间分配不灵活，运算的空间复杂度高。因此可用**链式存储结构**。

### 案例二：图书管理系统
- **需求**：查找、插入、删除、修改、排序、计数。
- **抽象**：可抽象为线性表。

### 案例引入小结
- 线性表中数据元素的类型可以为简单类型，也可以为复杂类型。
- 许多实际应用问题所涉及的基本操作有很大相似性，不应该为每个具体应用单独编写一个程序。

## 2.3 线性表的类型定义

### 抽象数据类型（ADT）定义

```text
ADT List {
    数据对象：D = {a_i | a_i ∈ ElemSet, (i = 1, 2, ..., n, n ≥ 0)}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, (i = 2, 3, ..., n)}
    基本操作：
        InitList(&L);              DestroyList(&L);
        ListInsert(&L, i, e);      ListDelete(&L, i, &e);
        ......等等
} ADT List
```

### 基本操作详解

#### 1. 创建与销毁
- **InitList(&L)** (Initialization List)
  - **操作结果**：构造一个空的线性表 $L$。
- **DestroyList(&L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：销毁线性表 $L$。
- **ClearList(&L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：将线性表 $L$ 重置为空表。

#### 2. 状态查询
- **ListEmpty(L)**
  - **初始条件**：线性表 $L$ 已经存在 ($n = 0$)。
  - **操作结果**：若线性表 $L$ 为空表，则返回 `TRUE`；否则返回 `FALSE`。
- **ListLength(L)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：返回线性表 $L$ 中的数据元素个数 ($n$)。

#### 3. 数据访问与定位
- **GetElem(L, i, &e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)}$。
  - **操作结果**：用 $e$ 返回线性表 $L$ 中第 $i$ 个数据元素的值。
- **LocateElem(L, e, compare())**
  - **初始条件**：线性表 $L$ 已经存在，`compare()` 是数据元素判定函数。
  - **操作结果**：返回 $L$ 中第 $1$ 个与 $e$ 满足 `compare()` 的数据元素的位序。若这样的数据元素不存在则返回值为 $0$。
- **PriorElem(L, cur_e, &pre_e)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：若 `cur_e` 是 $L$ 的数据元素，且不是第一个，则用 `pre_e` 返回它的前驱；否则操作失败，`pre_e` 无意义。
- **NextElem(L, cur_e, &next_e)**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：若 `cur_e` 是 $L$ 的数据元素，且不是最后一个，则用 `next_e` 返回它的后继；否则操作失败，`next_e` 无意义。

#### 4. 插入与删除
- **ListInsert(&L, i, e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)} + 1$。
  - **操作结果**：在 $L$ 的第 $i$ 个位置之前插入新的数据元素 $e$，$L$ 的长度加一。
    - 插入前（长度为 $n$）：$(a_1, a_2, ..., a_{i-1}, a_i, ..., a_n)$
    - 插入后（长度为 $n+1$）：$(a_1, a_2, ..., a_{i-1}, \textbf{e}, a_i, ..., a_n)$
- **ListDelete(&L, i, &e)**
  - **初始条件**：线性表 $L$ 已经存在，$1 \le i \le \text{ListLength(L)}$。
  - **操作结果**：删除 $L$ 的第 $i$ 个数据元素，并用 $e$ 返回其值，$L$ 的长度减一。
    - 删除前（长度为 $n$）：$(a_1, a_2, ..., a_{i-1}, a_i, a_{i+1}, ..., a_n)$
    - 删除后（长度为 $n-1$）：$(a_1, a_2, ..., a_{i-1}, a_{i+1}, ..., a_n)$

#### 5. 遍历
- **ListTraverse(&L, visited())**
  - **初始条件**：线性表 $L$ 已经存在。
  - **操作结果**：依次对线性表中每个元素调用 `visited()`。
